# AURELLE Jewellery Store

## تشغيل المشروع

المشروع مش محتاج تثبيت مكتبات أو تشغيل أوامر.

1. افتح فولدر المشروع في VS Code.
2. افتح `index.html` في المتصفح.
3. يفضل استخدام إضافة **Live Server**.

## تحميل المشروع من GitHub

قبل البداية، لازم يكون **Git** و**VS Code** متثبتين على الجهاز.

1. افتح صفحة الريبو على GitHub.
2. اضغط على زر **Code**.
3. اختار **HTTPS** وانسخ رابط الريبو.
4. افتح Terminal في المكان اللي عايز تحفظ فيه المشروع.
5. شغّل الأوامر دي بعد استبدال الرابط برابط الريبو الحقيقي:

```bash
git clone https://github.com/USERNAME/REPOSITORY.git
cd REPOSITORY
code .
```

لو أمر `code .` مشتغلش، افتح VS Code واختار **File > Open Folder**، وبعدها اختار فولدر المشروع.

### تحميل المشروع من داخل VS Code

ممكن تعمل نفس الخطوات من غير Terminal:

1. افتح VS Code.
2. اضغط `Ctrl + Shift + P`.
3. اكتب `Git: Clone` واختاره.
4. الصق رابط الريبو.
5. اختار مكان حفظ المشروع.
6. اضغط **Open** بعد انتهاء التحميل.

## تبدأ شغلك إزاي؟

قبل ما تبدأ، حمّل آخر تعديلات موجودة على الفرع الرئيسي:

```bash
git switch main
git pull origin main
```

بعدها اعمل Branch جديد للصفحة بتاعتك. خلي اسمه واضح ومن غير مسافات:

```bash
git switch -c products-page
```

أمثلة لأسماء مناسبة:

```text
products-page
cart-page
product-details-page
contact-page
```

كل شخص يستخدم Branch مختلف، ومتشتغلوش كلّكم مباشرة على `main`.

## إضافة ملفاتك

ضيف الملفات في الأماكن المخصصة ليها:

```text
pages/products.html
include/css/products.css
assets/images/products/product-name/01.jpg
```

بعد إضافة أو تعديل الملفات، راجع اللي اتغير:

```bash
git status
```

ضيف ملفات صفحتك فقط إلى الـCommit:

```bash
git add pages/products.html
git add include/css/products.css
git add assets/images/products/product-name
```

ممكن تضيف كل التعديلات باستخدام `git add .`، لكن استخدمه بس بعد مراجعة `git status` والتأكد إن كل الملفات الظاهرة تخصك.

## رفع تعديلاتك على GitHub

بعد ما تخلص صفحتك وتجربها:

1. راجع الملفات:

```bash
git status
```

2. اعمل Commit باسم واضح:

```bash
git commit -m "Add products page"
```

3. ارفع الـBranch لأول مرة:

```bash
git push -u origin products-page
```

غيّر `products-page` لاسم الـBranch بتاعك.

بعد أول مرة، أي تعديلات جديدة على نفس الـBranch تترفع كده:

```bash
git add pages/products.html include/css/products.css
git commit -m "Update products page"
git push
```

## إضافة شغلك إلى الفرع الرئيسي

بعد رفع الـBranch:

1. افتح الريبو على GitHub.
2. اضغط **Compare & pull request**.
3. اكتب وصف مختصر للتعديلات.
4. اضغط **Create pull request**.
5. استنى مراجعة الفريق قبل دمج التعديلات في `main`.

لو زر **Compare & pull request** مش ظاهر، افتح تبويب **Pull requests** واضغط **New pull request**، وبعدها اختار الـBranch بتاعك.

لو ظهر خطأ Permission أثناء الرفع، اتأكد إنك مضاف كـCollaborator في الريبو ومسجل دخولك على GitHub.

## إضافة صفحة جديدة

كل صفحة داخلية تتحط في فولدر `pages`، ويكون ليها ملف CSS منفصل عشان نقلل التعارض بين شغل الفريق.

مثال:

```text
pages/products.html
include/css/products.css
```

اربط ملف CSS داخل الصفحة بالشكل ده:

```html
<link rel="stylesheet" href="../include/css/products.css" />
```

المسارات داخل صفحات `pages` بتبدأ بـ`../`:

```html
<a href="../index.html">الرئيسية</a>
<img src="../assets/images/products/gold-ring/01.jpg" alt="خاتم ذهبي" />
```

أما المسارات داخل `index.html` مش محتاجة `../`:

```html
<img src="assets/images/products/gold-ring/01.jpg" alt="خاتم ذهبي" />
```

## قواعد شغل الفريق

- كل شخص يشتغل على ملف HTML وملف CSS خاصين بصفحته.
- متعدّليش `style.css` إلا لو التعديل مطلوب في الصفحة الرئيسية.
- حط الصفحات داخل `pages` فقط.
- حط الصور والخطوط والأيقونات داخل `assets`، مش جنب ملفات HTML.
- استخدم أسماء ملفات إنجليزية صغيرة ومن غير مسافات.
- استخدم الشرطة `-` بين الكلمات، مثال: `product-details.html`.
- متغيرش اسم ملف أو فولدر مش مسؤول عنه قبل ما تنسق مع الفريق.
- اعمل Pull قبل بداية الشغل لتقليل تعارضات Git.

## الخطوط

الخطوط موجودة محليًا داخل `assets/fonts`، لذلك المشروع لا يعتمد على Google Fonts.

| الخط | الاستخدام | الأوزان المتاحة |
|---|---|---|
| Noto Kufi Arabic | النصوص والعناوين العربية | 400 و600 |
| Cormorant Garamond | اسم البراند والنص الإنجليزي | 400 و600 |
| Manrope | متاح للاستخدام في الصفحات القادمة | 400 و600 |

تعريف الخط بيكون في أول ملف CSS:

```css
@font-face {
  font-family: "Noto Kufi";
  src: url("../../assets/fonts/noto-kufi-arabic-arabic-400-normal.woff2")
    format("woff2");
  font-weight: 400;
  font-style: normal;
}
```

## الأوزان

- `400`: النص العادي.
- `600`: العناوين والنص الأوضح.

متستخدمش وزن غير موجود في ملفات الخطوط.

## أحجام الخطوط المقترحة

| العنصر | الحجم |
|---|---:|
| النص العادي | `14px` |
| النص الصغير | من `8px` إلى `12px` |
| اسم المنتج | من `15px` إلى `17px` |
| عنوان الكارت | `20px` |
| عنوان القسم | من `38px` إلى `50px` |
| العنوان الرئيسي | من `44px` إلى `74px` |

استخدم `px` للأحجام والمسافات الثابتة، وجرّب النتيجة على الموبايل بعد أي تعديل.

## إضافة صور المنتجات

كل منتج يكون له فولدر منفصل داخل `assets/images/products`:

```text
assets/images/products/gold-ring/
├── 01.jpg
└── 02.jpg
```

- اسم فولدر المنتج يكون مختصر وبالإنجليزي.
- الصور تتسمى `01.jpg` و`02.jpg` وهكذا.
- اكتب وصف مناسب داخل `alt`.
- متستخدمش مسار من جهازك الشخصي داخل HTML.

## الأيقونات

الأيقونات موجودة داخل `assets/icons` بصيغة SVG.

```html
<img src="../assets/icons/search.svg" alt="بحث" />
```

لو الأيقونة للزينة فقط، استخدم `alt=""`.

## قواعد HTML

- الصفحة العربية تبدأ بـ`<html lang="ar" dir="rtl">`.
- استخدم عنوان `h1` واحد فقط في الصفحة.
- استخدم `h2` لعناوين الأقسام و`h3` للعناصر داخلها.
- خلي كل صورة مهمة لها وصف `alt`.
- استخدم عناصر واضحة مثل `header` و`main` و`section` و`footer`.
- لا تكتب CSS داخل ملف HTML.

## قواعد CSS

- كل خاصية تنتهي بـ`;`.
- كل `{` لازم تتقفل بـ`}`.
- خلي كل خاصية في سطر منفصل.
- حط تنسيق كل جزء تحت تعليق باسمه.
- متستخدمش `!important` إلا عند الضرورة.
- متغيرش أسماء الـClasses المشتركة بدون تنسيق مع الفريق.
- لو أضفت Responsive، اختبر الصفحة على الكمبيوتر والموبايل.

## ملف `.htaccess`

الملف مخصص لسيرفر Apache، وبيظبط الصفحة الرئيسية، الـCache، الضغط، وبعض إعدادات الحماية. الصفحة تشتغل محليًا من غيره، وGitHub Pages لا يستخدم إعداداته.

## الـResponsive — اختياري

إضافة الـResponsive اختيارية، وتتحط في آخر ملف CSS الخاص بالصفحة بعد كل التنسيقات الأساسية.

لو هتضيفه، ممكن تستخدم النقطتين دول:

```css
/* التابلت */
@media (max-width: 960px) {
}

/* الموبايل */
@media (max-width: 680px) {
}
```

- التصميم الأساسي بيكون للكمبيوتر.
- عند `960px` ممكن تقلل الأعمدة والمسافات.
- عند `680px` ممكن تخلي الأقسام تحت بعضها.
- لو الصفحة مش محتاجة Responsive، مش لازم تضيف الـMedia Queries.
